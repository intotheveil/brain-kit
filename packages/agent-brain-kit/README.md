# agent-brain-kit

**This is an alias package.** It installs and runs [`brain-kit`](https://www.npmjs.com/package/brain-kit)
— same tool, same version, the agent-neutral name.

```bash
npx agent-brain-kit init  myrepo
npx agent-brain-kit apply myrepo
```

Full documentation, and the reason any of this exists:
**https://github.com/intotheveil/brain-kit**

Why three names: people look for this under "claude", under "agent", and under "brain-kit". Rather
than pick one and be invisible to the other two searches, all three resolve to a single
implementation — there is no forked copy to drift.
