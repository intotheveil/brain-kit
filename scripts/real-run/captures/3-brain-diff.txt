+- **Stack:** Node.js, ES modules (`"type": "module"`), zero dependencies. Plain `node:http`
+  server; tests use the built-in `node:test` runner. No framework, no DB, no build step.
+- **Data model:** a single in-process `Map` in `src/store.js`: `code -> { url, hits }`.
+  No schema, no migrations, no persistence. Codes are 6 chars of base62 (`0-9a-zA-Z`),
+  generated with `Math.random()` (not cryptographically secure, so codes are guessable).
+  On collision `shorten` retries up to 5 times, then throws `code space exhausted`.
+- **Key modules / where things live:**
+  - `src/store.js`: `code()`, `shorten(url)`, `resolve(code)` (increments `hits`, returns url or null), `stats(code)` (returns `{url, hits}` or null).
+  - `src/server.js`: HTTP entry point and routing (below). Port comes from `PORT`, default 8080.
+  - `test/store.test.js`: store tests only (round trip, rejects non-http). The server has no tests.
+- **HTTP routes** (`src/server.js`):
+  - `POST /shorten` with JSON `{"url": "..."}`: 201 `{"code": "..."}`; 400 with a plain-text message for a bad URL, bad JSON or an exhausted code space.
+  - `GET /s/<code>`: 200 with `{url, hits}` JSON, or 404 with body `null`.
+  - `GET /<code>`: 302 to the stored URL (and `hits++`), otherwise 404 `not found`. Any method works here, not just GET.
+- **External services / keys:** none. The only env var is `PORT`.
+- **How to run / build / test / deploy:** `npm start` (runs `node src/server.js`), `npm test`
+  (runs `node --test`). There is no build, lint or typecheck script. No deploy setup.
+  Quick check: `curl -X POST localhost:8080/shorten -d '{"url":"https://example.com"}'`.
+- **Integration points:** `server.js` imports `shorten`, `resolve` and `stats` from `store.js`.
+  Nothing else; no outside systems. The repo has no git remote.
